# Holistic – Hospital Appointment System (Vue 3 + Vite + Vue Router, frontend only)
    npm install && npm run dev
Flow: Landing → Signup → Login → Dashboard → Appointments / Patients / Doctors → Details → Logout.
Data: localStorage (users, isLoggedIn, currentUser, hms2_doctors, hms2_patients, hms2_appts), seeded on first launch.
Photos load from randomuser.me (internet needed); initials avatars are the offline fallback.
